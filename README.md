# Olá, sou Rafael B. Dev 👋

Sou desenvolvedor do **3DE**, um ambiente acadêmico de modelagem CAD 3D paramétrica que funciona diretamente no navegador.

## 🧊 Projeto em destaque: 3DE

O 3DE reúne criação de projetos, esboços, modelagem de sólidos, extrusões, cortes, inspeção e navegação 3D em uma interface própria, escura e em português do Brasil.

[![Abrir o 3DE](https://img.shields.io/badge/Abrir_o_3DE-48C9B0?style=for-the-badge&logo=streamlit&logoColor=white)](https://3de-cad.streamlit.app/)
[![Código do projeto](https://img.shields.io/badge/Código_no_GitHub-181717?style=for-the-badge&logo=github)](https://github.com/RBuonoDev/cad-vision/tree/3de)

### Recursos atuais

- Modelagem CAD 3D no navegador
- Esboços e ferramentas paramétricas
- Extrusão, corte e operações de sólidos
- Importação de STEP, IGES e malhas
- Interface em português do Brasil
- Temas Claro, Escuro e Win 95

### Tecnologias

Rust · WebAssembly · WebGPU · Streamlit · GitHub
